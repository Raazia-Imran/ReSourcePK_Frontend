ReThread Frontend — Software Requirements
========================================

This project is implemented in JavaScript, not Python. This file is an
inventory for developers; do not install it with pip. Use npm ci to install the
exact dependency tree recorded in package-lock.json.

RUNTIME
-------
Node.js: use Node.js 24 to match the backend; Vite 8 requires a supported
modern Node.js release.
npm: version shipped with the selected Node.js installation
A modern web browser for using the application.

ENVIRONMENT SETTINGS
--------------------
VITE_API_URL: backend API base URL, such as http://localhost:5000/api/v1.
VITE_GOOGLE_CLIENT_ID: public Google OAuth Web client ID. Add each deployed
frontend origin to the OAuth client's authorized JavaScript origins.
These VITE_ values are included in the browser build. Never put passwords,
private keys, webhook signing salts, or other backend secrets in frontend env.

The frontend calls the separately deployed Node.js/Express backend. Configure
VITE_API_URL for the deployment, and configure the backend CORS_ORIGINS and
APP_URL values to allow the frontend's exact origin. Google sign-in also needs
the matching OAuth origin and redirect setup.
