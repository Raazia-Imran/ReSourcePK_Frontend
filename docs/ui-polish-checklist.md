## Verification

`npm run lint`, `npm run format:check`, `npm run build`, and `CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/ui-smoke.cjs`.

Browser checks use isolated synthetic API fixtures, not the live backend. Matrix covers 48 route/role combinations at 320, 360, 390, 768, 1024, 1280 and 1440px, including all role profiles. Additional checks cover drawer Escape/focus restoration, empty/error data, expanded tier/image controls, filter reset, profile navigation and sticky mobile header. These checks do not prove real payment processing or personal-profile editing.

The animations use browser-native APIs and CSS; no new production dependency. The Framer marketplace reference could not be retrieved. Physical devices and Safari/Firefox remain outside the Chromium verification.
